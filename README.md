## 🇬🇧 English

### 📦 About
AudioManager is a desktop application designed to help users manage audio devices and streaming-related features through a clean and simple interface.

This public repository is used for **distribution only**.
Only the compiled application file is provided here.

**🌐 Available languages:** English, French, Spanish

### ⬇️ Download
You only need to download the executable file:

- `AudioManager`

No source code is included in this repository.
No Python installation is required for the distributed executable build.

### ▶️ Run the application
#### Linux
1. Download `AudioManager`
2. Make it executable:
   ```bash
   chmod +x AudioManager
   ```
3. Launch it:
   ```bash
   ./AudioManager
   ```

### 📁 Repository purpose
This repository is intended only to:
- distribute the application
- provide a simple download point
- avoid publishing the private source code

### 🔒 Source code
The AudioManager source code is **private** and is not available in this public repository.

### ⚠️ Important
If your system blocks the application:
- verify that you downloaded the correct file for your operating system
- make sure the file has execution permission
- launch it from a terminal to check possible error messages
